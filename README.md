# horizontic

## Descripción

Proyecto horizontic creado con Forge.

## Tecnología

Por definir

## Instalación

```bash
# Iniciar el proyecto
forge start horizontic
```

## Estructura

```
horizontic/
├── .forge          # Configuración de Forge
├── .gitignore      # Archivos ignorados por Git
├── README.md       # Este archivo
├── config/         # Configuraciones
├── docs/           # Documentación
├── scripts/        # Scripts útiles
└── tests/          # Tests
```

## Comandos útiles

```bash
# Ver estado
forge status horizontic

# Ver logs
forge logs horizontic

# Detener
forge stop horizontic
```
